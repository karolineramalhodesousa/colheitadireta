# Colheita Direta

Plataforma que conecta pequenos agricultores familiares diretamente com consumidores, combatendo a fome e promovendo agricultura sustentável através da venda direta de alimentos frescos.

## 🌱 Sobre o Projeto

Plataforma que conecta pequenos agricultores familiares diretamente com consumidores, combatendo a fome e promovendo agricultura sustentável através da venda direta de alimentos frescos.

### Objetivos Principais
- Reduzir o desperdício de alimentos
- Garantir preços justos para agricultores
- Oferecer alimentos frescos e nutritivos para as comunidades
- Promover a agricultura familiar sustentável

## 🚀 Como Rodar o Projeto

### Pré-requisitos
- Node.js (versão 14 ou superior)
- npm ou yarn

### Passo a Passo

1. **Abra o terminal ou prompt de comando**

2. **Navegue até o diretório do projeto:**

3. **Instale as dependências:**
   ```bash
   npm install
   ```
   ou se usar yarn:
   ```bash
   yarn install
   ```

4. **Abra o navegador:**
   O projeto abrirá automaticamente em `http://localhost:3000`

## 🛠️ Tecnologias Utilizadas

### Frontend
- **React 18.2.0**: Biblioteca JavaScript para criar interfaces de usuário
- **React Router DOM 6.8.0**: Para navegação entre páginas
- **Create React App 5.0.1**: Ferramenta de desenvolvimento React

### Estilização
- **CSS Puro**: Estilos customizados sem frameworks externos
- **CSS Grid e Flexbox**: Para layouts responsivos
- **Design Responsivo**: Adaptação para mobile e desktop
